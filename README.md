# هوهو علوم — علوم تجربی سوم دبستان

اپ اندروید آموزش علوم سوم دبستان، صفحه به صفحه مطابق کتاب درسی ۱۴۰۵. هوهو (جغد معلم) هر
صفحه‌ی کتاب را با صدا درس می‌دهد و روی تصویرهای خودِ کتاب زوم می‌کند، دورشان حلقه‌ی نورانی
می‌کشد و کودک خودش روی تصویر جواب را پیدا می‌کند.

- ۱۴ درس، ۱۲۲ صفحه (صفحه‌ی ۷ تا ۱۲۸)، هر صفحه یک درس صوتی
- مرور هر بخش، تمرین، کاربرگ ۳ سطحی و آزمون برای هر درس
- پنل والدین، نقشه‌ی مسیر، ستاره و مدال
