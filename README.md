# هوهو فارسی — فارسی سوم دبستان

اپ اندروید آموزش فارسی سوم دبستان، صفحه به صفحه مطابق کتاب درسی (کد ۳۰۳). هوهو (جغد معلم)
هر صفحه‌ی کتاب را با صدا درس می‌دهد: متنِ درس را برای کودک تعریف می‌کند، واژه‌های تازه را معنی
می‌کند، شعرها را می‌خواند و تصویرهای خودِ کتاب را، بریده و متحرّک، روی صحنه نشان می‌دهد.

- ۱۷ درس در ۷ فصل، ۱۱۹ صفحه (ستایش صفحه‌ی ۱۰ تا نیایش صفحه‌ی ۱۲۸)، هر صفحه یک قسمتِ صوتی
- «بخوان و حفظ کن»، «بخوان و بیندیش»، مَثَل‌ها و حکایت‌ها هم جزوِ درسِ خودشان هستند
- مرور هر بخش، تمرین، کاربرگ ۳ سطحی و آزمون برای هر درس
- پنل والدین، نقشه‌ی مسیر، ستاره و مدال
